# connectedrenter.com — static rebuild

Rebuild of Connected Renter ("Connecting Made Easy"), the renter resource hub that went down.
Plain HTML/CSS/JS generated by Python — no WordPress, database or plugins.

- **Live preview:** https://mistyrose-hummingbird-828395.hostingersite.com/
- **Hostinger:** Agency Growth plan, website UID `59z2Fco9q` (php-fpm 8.3), domain `connectedrenter.com` attached — point DNS at it to go live.

## Rebuild & deploy

```sh
python3 build.py      # regenerate every page (stdlib only; Pillow optional for the OG image)
python3 validate.py   # links, assets, one H1, JSON-LD, unique titles/descriptions, homepage keyword count
./deploy.sh           # see the header comment for the three upload credentials
```

`index.php` serves `home.html` for `/`, 301s old WordPress/WooCommerce URLs and returns `404.html`
with a real 404 (the host ignores `.htaccess`). Preview locally with `python3 -m http.server` and open `/home.html`.

## Design

"Moving day" concept: Fraunces serif headlines with italic accents, Caveat handwriting, DM Sans body, and the
original gold #DBA622 / maroon #680404 / red #ff2a13. Homepage pieces: full-photo hero with a moving-day ⇄
move-in-day toggle, a pinned scroll story where a truck drives along the road, resources as cardboard boxes,
tools as sticky notes on a corkboard, a pinned horizontal guide gallery, myth-vs-fact flip cards, a glowing
Texas map, and courses as tickets. All motion respects `prefers-reduced-motion`.

Photos: 23 Unsplash-License images listed in `photos.json` (credited on /about-us/), stored as
`assets/img/photos/<slot>-{800,1600}.webp`.

## Source layout

- `content/resources.py`, `content/blog.py` — page copy
- `tools.py` (tool markup + tool page copy), `assets/js/tools.js` (tool logic)
- `build.py` (layout, schema, sitemap, search index), `icons.py` (SVG sprite)
- `assets/css/site.css`, `assets/js/site.js` — design system and effects

## Known gaps

- Contact, newsletter, shop and course forms open the visitor's email app (`mailto:`); there's no server-side form handler or checkout.
- Cost figures in guides and tools are labelled planning estimates.
- The original page copy couldn't be recovered (Wayback Machine unreachable from the build environment), so the copy is new; the 3 original blog images, logo and merch photo were reused.
