# connectedrenter.com — static rebuild

Rebuild of Connected Renter ("Connecting Made Easy"), the renter resource hub that went down.
Plain HTML/CSS/JS generated by Python — no WordPress, database or plugins.

- **Live:** https://connectedrenter.com/ (preview: https://mistyrose-hummingbird-828395.hostingersite.com/)
- **Hostinger:** Agency Growth plan, website UID `59z2Fco9q` (php-fpm 8.3), domain `connectedrenter.com` attached — point DNS at it to go live.

## Rebuild & deploy

```sh
python3 build.py      # regenerate every page (stdlib only; Pillow optional for the OG image)
python3 validate.py   # links, assets, one H1, JSON-LD, unique titles/descriptions, homepage keyword count
./deploy.sh           # see the header comment for the three upload credentials
```

`index.php` serves `home.html` for `/`, 301s old WordPress/WooCommerce URLs and returns `404.html`
with a real 404 (the host ignores `.htaccess`). Preview locally with `python3 -m http.server` and open `/home.html`.

## Design

"Moving day" concept: Fraunces serif headlines with italic accents, Caveat handwriting, DM Sans body, and the
original gold #DBA622 / maroon #680404 / red #ff2a13. Homepage pieces: full-photo hero with a moving-day ⇄
move-in-day toggle, a pinned scroll story where a truck drives along the road, resources as cardboard boxes,
tools as sticky notes on a corkboard, a pinned horizontal guide gallery, myth-vs-fact flip cards, a glowing
Texas map, and courses as tickets. All motion respects `prefers-reduced-motion`.

Photos: 23 Unsplash-License images listed in `photos.json` (credited on /about-us/), stored as
`assets/img/photos/<slot>-{800,1600}.webp`.

## SEO & analytics

- Google tag `G-E1CR5DK1LV` in the `<head>` of every page (including 404); GSC verification file
  `googlecccfbf2f7e9e5ae4.html` at the root.
- Titles ≤ 60 characters (`fit_title()` drops the brand suffix when needed), unique meta descriptions,
  https canonical, Open Graph/Twitter tags with image dimensions, JSON-LD (Organization, WebSite,
  BreadcrumbList, FAQPage, Article/BlogPosting, WebApplication, Course, ItemList, HowTo).
- `sitemap.xml` (every page, lastmod), `robots.txt` (points to the sitemap, disallows `/home.html`),
  favicon set (`favicon.ico`, 32/48/192/512 PNGs, apple-touch-icon, web manifest).
- Redirects: `http://` and `www.` → `https://connectedrenter.com` for `/` and unknown paths via `index.php`.
  The Agency host has no force-HTTPS switch and serves static files directly, so pages also carry a tiny
  inline script that moves plain-http visitors to https. Don't 301 the `*.hostingersite.com` preview host —
  Hostinger rewrites the Location header back to the preview host and it loops; canonicals cover it.
- `validate.py` enforces all of the above (Google tag, title length, canonicals, sitemap coverage, root files).

## Renter Shop (Amazon affiliate)

`/shop/` lists 28 Amazon products for renters in 7 categories; each has a page at `/shop/<slug>/` with a
"Buy now on Amazon" button linking to `https://www.amazon.com/dp/<ASIN>?tag=connectedrenter-20`
(`rel="sponsored nofollow"`). Product data is in `products.json` (from Amazon listings); the
"why renters love it" copy is in `content/products.py`. Following Amazon Associates rules, pages show the
required disclosure and do **not** show prices or star ratings (those may only come live from Amazon's
Product Advertising API). Images hotlink Amazon's CDN. To add a product, append it to `products.json`
(and a blurb to `WHY`), then rebuild.

## Known gaps

- Contact, newsletter and course forms open the visitor's email app (`mailto:`); there's no server-side form handler or checkout.
- Cost figures in guides and tools are labelled planning estimates.
- The original page copy couldn't be recovered (Wayback Machine unreachable from the build environment), so the copy is new; the 3 original blog images, logo and merch photo were reused.
