# Content files (thesublet.com)

All files here are plain PHP that `return` an array. Every file MUST start with:

    <?php defined('APP') || exit;

## Cities — `cities/*.php`

Each file returns an array keyed by `"{state}/{city-slug}"` (lowercase 2-letter
state code, `dc` for Washington DC; city slug = lowercase, hyphenated, ASCII).

```php
<?php defined('APP') || exit;
return [
  'ny/new-york' => [
    'name'   => 'New York',          // city display name
    'state'  => 'NY',
    'type'   => 'metro',             // 'metro' or 'college'
    'lat'    => 40.7128, 'lng' => -74.0060,   // city center, 4 decimals
    'tagline'=> 'One sentence summary shown under the H1.',
    'intro'  => '<p>…</p><p>…</p>',   // 2–3 paragraphs, 150–250 words, HTML (<p>, <strong>, <em> only)
    'neighborhoods' => [             // 5–8 real, well-known neighborhoods/areas
      ['name' => 'Astoria', 'blurb' => '1–2 sentences: character, who it suits, transit link.'],
    ],
    'prices' => '<p>…</p>',          // CAUTIOUS price guidance, see rules
    'transit'=> '<p>…</p>',          // real transit systems / airports / car-dependence
    'tips' => [                      // 2–3 sentences each, specific to the city
      'interns'  => '…',
      'nurses'   => '…',             // travel nurses: name major real hospital systems/medical centers you are sure exist
      'students' => '…',             // name real universities in/near the city
      'seasonal' => '…',             // when demand peaks (summer, academic calendar, events) — only well-known patterns
    ],
    'faqs' => [                      // 3–4 Q&As unique to this city
      ['q' => '…?', 'a' => '…'],
    ],
  ],
];
```

## Blog posts — `blog/{slug}.php`

```php
<?php defined('APP') || exit;
return [
  'slug'        => 'how-to-sublet-legally',
  'title'       => 'How to Sublet Your Apartment Legally (Without Upsetting Your Landlord)',
  'description' => '150–160 char meta description.',
  'date'        => '2026-10-02',     // YYYY-MM-DD, spread between 2026-06-01 and 2026-11-15
  'category'    => 'Guides',         // Guides | Renters | Hosts | Travel Nurses | Interns | Students | Safety
  'read_min'    => 7,
  'body'        => <<<'HTML'
<p>…</p><h2>…</h2><p>…</p><ul><li>…</li></ul>
HTML,                                // 1,100–1,600 words. Use <h2>, <h3>, <p>, <ul>, <ol>, <li>, <strong>, <em>, <table>, <blockquote>.
                                     // Internal links allowed: /sublets/, /post-a-sublet/, /tools/…, /blog/{other-slug}/, /safety/
  'faqs'        => [ ['q' => '…?', 'a' => '…'], ],   // 4–5
  'amazon'      => [ ['label' => 'Packing cubes', 'query' => 'packing cubes set'], ],  // 4–6 product ideas relevant to post
];
```

Amazon links are generated by the app from `query` (search links with the
affiliate tag) — never write Amazon URLs yourself.
