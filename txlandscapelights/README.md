Static site for a statewide Texas landscape lighting business, generated by Python
(standard library only) and served from a plain php-fpm Hostinger Agency website.

blog, FAQ, quote forms) with a new design and Texas-wide content.

## Build, check, deploy

```sh

python3 validate.py   # links, titles, H1s, JSON-LD, homepage keyword count (≥14)
./deploy.sh           # needs TL_FB_URL / TL_FB_AUTH / TL_FB_REST, see header comment
```

| `tools-dev/` | Local helpers: screenshot scripts, PHP dev router, OG image template |

## Hosting notes

- The platform ignores `.htaccess` and routes `/` and unknown paths to `index.php`, so the
  homepage is `home.html` served by `index.php`, which also does the `www`/`http` 301s,
  trailing-slash 301s and real 404s. Never add a root `index.html`.
- `app/lead.php` handles every form (quote sections, contact, quote page, popup). It emails
  info@txlandscapelights.com via PHP `mail()` and appends each lead to `leads/leads.csv`
  one level above `public_html` (not web-reachable), so nothing is lost before the mailbox
  exists. Spam guards: honeypot field, minimum fill time, link-count check.
- Weather on the homepage is live from Open-Meteo (no key). Sunset planner math runs in the
  browser.
- Popup opens 4 s after load, once per browser session; after a dismissal it stays quiet
  for 2 days, and never shows on /quote/, /contact/ or /thank-you/ or after a submission.
