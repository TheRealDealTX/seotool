# comeicavoliamerenda.com — rebuild

Static rebuild of the expired domain **comeicavoliamerenda.com** as *Come i Cavoli a
Merenda*, an independent earring & ear-piercing guide (the topic the domain ranked for
in 2017). Python standard library only.

```sh
python3 build.py      # writes the site into dist/
python3 validate.py   # titles, descriptions, links, assets, JSON-LD, old-URL coverage
./deploy.sh           # upload dist/ to Hostinger (see header for credentials)
```

## Hosting

## SEO / tracking

- Google tag `G-5HJ1T79TVS` (GA4) is the first thing in every page's `<head>` (`GTAG` in `build.py`).
- Search Console file verification: `static/googlecccfbf2f7e9e5ae4.html` (served from the root).
- Favicons: `favicon.ico` (16/32/48), `favicon.svg`, `favicon-96x96.png`, `apple-touch-icon.png`,
  `site.webmanifest` with 192/512 icons.
- Each page: unique title (≤60 chars) and description, canonical, robots `max-image-preview:large`,
  Open Graph + Twitter cards with a 1200×630 JPG (`assets/img/og/`), JSON-LD (Organization, WebSite,
  Article, BreadcrumbList, FAQPage, CollectionPage/ItemList), LCP image preload.
- `sitemap.xml` includes image entries; `robots.txt` points to it.
- `validate.py` enforces all of the above.

The host serves existing files directly, ignores `.htaccess`, and sends unknown paths to
`index.php`, so the homepage is `home.html` (there is deliberately no root `index.html`).

## Pages (54)

Article copy lives in `content/<category>.py` (format: `content/SPEC.md`).

## Old URLs (from the Semrush exports in `data/`)

- `data/old-organic-urls.tsv`: 3,726 URLs that ranked in 2017 (Semrush organic positions).
- `data/backlink-targets.tsv`: 96 URLs with backlinks.
- `data/redirect-report.tsv`: what happens to each one (generated by `build.py`).

The old site was an auto-generated earring image gallery: about 750 slug URLs plus
~3,000 `-<16 hex>.html` duplicate pages. Every one of the 107 URLs that had traffic is
rebuilt as a clean page or 301'd to the page that now covers its topic; 1,887 old URLs
in total are 301'd by keyword rules (`RULES` in `build.py`). Old URLs with no traffic and
no matching topic return a real 404.

Backlinks: almost all point to `/` (2,315 referring domains, mostly recent spam/PBN
anchors). The remaining editorial links point to the domain's earlier life as an Italian
food blog (`/2013/09/...html` Blogger posts); those 301 to the homepage. Scraper-era
`*.pdf` URLs are answered with 410/404.
