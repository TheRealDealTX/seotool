How to use the favicon checker & generator

  1. Enter a website URL to check its declared favicons, /favicon.ico, Apple touch icon and web manifest.

FAQ

Common questions

Which favicon sizes do I need?

A practical modern set is favicon.ico (16, 32 and 48px inside), a 180×180 apple-touch-icon.png, and 192×192 plus 512×512 PNGs referenced from site.webmanifest. Add an SVG favicon if your logo is vector.

Why does my old favicon still show?

Browsers cache favicons aggressively. After updating, hard-refresh, open the icon URL directly, or rename the file (for example favicon.ico?v=2) to bust the cache.

Does a missing manifest break my website?

No. A web app manifest is optional for normal websites, but it provides icons for Android home screens and installable experiences.

Is my logo uploaded when generating?

No. The generator draws and encodes every icon in your browser. Only the website checker contacts a server, to fetch the public URL you enter.
