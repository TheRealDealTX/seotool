FAQ

Common questions

Do character counts include spaces?

The tool shows both: characters including spaces and line breaks, and characters without spaces. Counts use Unicode code points, so emoji count as one character.

What is a good Flesch reading ease score?

60–70 is plain English that most adults read easily. Web copy often aims for 60 or higher; technical or academic writing scores lower.

What keyword density should I aim for?

There is no magic number. Use your main phrase naturally in the title, first paragraph and headings. If a single word is far above 3–4% of the text, it may read as repetitive.

Is my text saved or uploaded?

Your draft autosaves to local storage on this device only, so a refresh won't lose it. Nothing is sent to a server. Use Clear to remove it.
