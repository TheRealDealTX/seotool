How it works

How to use the HTML, CSS & JS playground

  1. Pick a starter template or start blank. Write markup, styles and scripts in their own tabs.
  2. The preview refreshes automatically. Turn off Auto-run and press Ctrl/⌘ + Enter to run manually.
  3. Check console.log output and errors in the console panel, and switch device widths to test responsive layouts.
  4. Share a link that contains your code, or download a single self-contained HTML file.

What it can do

  • Separate HTML, CSS and JS editors with tab indentation
  • Auto-run live preview in an isolated sandbox
  • Console panel capturing logs, warnings and runtime errors
  • Responsive, laptop, tablet and mobile preview widths
  • Starter templates: landing hero, card grid, flexbox, animation
  • Autosaves locally; share links encode your code in the URL
  • Download everything as one HTML file
FAQ

Common questions

Is my code uploaded?

No. Code stays in your browser and autosaves to local storage on this device. Share links compress your code into the link itself — nothing is stored on a server.

Can I use external libraries?

Yes. Add script or link tags pointing to a CDN in the HTML tab. The preview can load external assets referenced by your code.

Can I run PHP or server code?

No. The playground runs front-end code in the browser. PHP, Node.js and other server languages need a server.

Why can't my script access cookies or the parent page?

The preview runs in a sandboxed frame with a unique origin. It can run JavaScript and show alerts but cannot read this site's storage or navigate the page — a safety feature.
