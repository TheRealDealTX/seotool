How it works

How to use the JSON formatter & viewer

  1. Paste JSON, drop a .json file onto the editor, or load the sample.
  2. Choose Format or Minify. Errors show the exact line and column with a pointer to the problem.
  3. Use Repair to fix comments, trailing commas, single quotes and unquoted keys automatically.
  4. Explore the Tree view, copy any value's path, or convert the data to CSV, YAML or TypeScript.

FAQ

Common questions

Why are comments and trailing commas rejected?

Standard JSON does not allow comments, trailing commas, single-quoted strings or unquoted keys. Use Repair to convert these JavaScript-style habits into valid JSON.

Will very large numbers stay exact?

JavaScript numbers have finite precision, so integers beyond 2^53 may change. Keep large IDs as quoted strings when exact digits matter.

How does JSON to CSV handle nested objects?

Nested objects are flattened into dotted column names such as address.city. Arrays of primitive values are joined with semicolons; the input should be an array of objects.

Is my JSON sent anywhere?

No. Parsing, formatting and conversion run entirely in your browser.
