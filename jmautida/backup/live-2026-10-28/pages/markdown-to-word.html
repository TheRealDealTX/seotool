Good to know

How to use Markdown to Word

Turn Markdown notes into an editable Word document. Preview your formatting while you write, import a local Markdown file, and export a genuine .docx document.

  1. Paste Markdown into the editor or choose Import .md to read a local file.
  2. Review the document preview. Headings, emphasis, lists, links, code blocks and tables are supported.
  3. Choose Export Word to download a DOCX file, or download the Markdown source to continue editing later.

Common questions

Does this create a real Word document?

Yes. Export produces a .docx archive containing Word document XML, not an HTML file renamed to .doc.

Are images and custom HTML supported?

Images are represented by alt-text placeholders. Custom HTML styling is not supported, and complex nested formatting may differ in Word.

Are documents sent to a server?

Conversion runs in your browser. Your text and imported files are not uploaded by this tool.
