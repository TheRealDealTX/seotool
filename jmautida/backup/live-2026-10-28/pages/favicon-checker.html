Good to know

How to use Favicon checker

Inspect the icons a website declares for browser tabs, iOS home screens and web app manifests. The report separates missing declarations from resources it could not fetch.

  1. Enter the full HTTP or HTTPS URL of a public website.
  2. Run the check to inspect favicon links, /favicon.ico, an Apple touch icon and a linked manifest.
  3. Review each result. Fix missing declarations or unreachable resources, then check the page again.

Common questions

Does a missing manifest mean my website is broken?

No. A web app manifest is optional for a standard website. Its icons and settings are useful for installable web experiences.

Does the tool check the actual image dimensions?

It checks resource reachability, response content types and declared sizes. It does not decode image dimensions or assess visual quality.

Why might a website check fail?

Some websites block automated requests or respond too slowly. The checker also rejects private network addresses, unsupported ports and resources larger than its limit.
