Good to know

How to use HTML playground

Try an idea before putting it into a project. This HTML playground runs a complete document in an isolated preview, with selectable mobile and tablet widths.

  1. Paste your HTML into the source editor. Include CSS in a style tag and JavaScript in a script tag.
  2. Choose Run code, or press Ctrl/Command + Enter, to refresh the preview.
  3. Select a preview width to inspect your layout, then download the HTML to keep your work.

Common questions

Can I run JavaScript and PHP?

JavaScript runs inside the sandboxed preview. PHP requires a server and is not executed by this browser tool.

Is my code uploaded?

Your code stays in this browser. External images, scripts or stylesheets referenced by your code can make network requests. Inputs are not saved when you leave.
