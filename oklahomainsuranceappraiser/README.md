# oklahomainsuranceappraiser.com

and served from a Hostinger Agency Growth website. Engineering was copied from the Georgia template;
content, URL slugs, palette, fonts and layout are new and differ from every sister site.

## Build, validate, deploy

```sh
python3 build.py        # writes ./public
python3 validate.py     # must print "OK — zero errors"
# fresh credentials from the Hostinger API call agency-hosting_files_generate-upload-url (website_uid 00PvJWQDP):
export GIA_FB_URL='https://…/api/tus'  GIA_FB_AUTH='…'  GIA_FB_REST='…'
./deploy.sh             # TUS upload of every file in ./public to public_html
```

Then clear the cache (`agency-hosting_cache_clear-website`). `deploy.sh` only adds/overwrites; when a page is
removed or renamed, delete the old file on the server with
`DELETE {url-without-/tus}/resources/public_html/<path>` using the same `X-Auth` / `X-Auth-Rest` headers.

Local test of the routing/guard (mimics the host: real files served directly, a directory's `index.php` executed):

```sh

curl -sI -H 'Host: www.oklahomainsuranceappraiser.com' http://127.0.0.1:8099/cities-we-serve/tulsa/
```

## Hosting notes: guard and why pages are `dir/index.php`

- The host ignores `.htaccess`, has no force-HTTPS switch on the Agency plan, and **serves real files directly
  without running the root `index.php`**. A `dir/index.html` page would skip any redirect logic, so
  `http://www.…/page/` would answer 200.
- Therefore the homepage is `home.html` (served by the front controller for `/`) and **every other page is
  `dir/index.php`** whose first line is `<?php require_once dirname(__DIR__, n) . '/_guard.php'; ?>` followed by
  static HTML containing no other PHP. Never write a root `index.html` or any `dir/index.html`; `build.py` aborts
  and `validate.py` fails if one appears. The only static `.html` files at the root are `home.html`, `404.html`
  and the Search Console file.
- `_guard.php` 301s `www.` and plain http (via `X-Forwarded-Proto`, falling back to `HTTPS`) to
  `https://oklahomainsuranceappraiser.com` on the real domain only; 301s `/dir/index.php` (and `/index.php`) to
  `/dir/`; sends `X-Robots-Tag: noindex, nofollow` on any other host (preview URL); and returns 404 if requested directly.
- `index.php` (front controller) requires the guard, serves `home.html` for `/`, adds trailing slashes to
  directories, includes `dir/index.php` for directory URLs that reach it, and returns `404.html` with a real 404.

## Google Search Console verification file

- File: `googlecccfbf2f7e9e5ae4.html` at the site root. Contents are exactly this single line — no HTML, guard,
  GTM, BOM or trailing newline:

  ```
  google-site-verification: googlecccfbf2f7e9e5ae4.html
  ```
- It is a constant in `build.py` (`GSC_FILE` / `GSC_BODY`) and rewritten byte-for-byte on every build, so a
  rebuild never drops it. It is excluded from the validator's page checks, `sitemap.xml`, the HTML site map and
  internal links; `robots.txt` doesn't block it. The host serves it directly (the guard doesn't run) — expected.
- It must stay at the root permanently: Google re-checks it, and removing it unverifies the URL-prefix property
  `https://oklahomainsuranceappraiser.com/`.

## Contact form (`api/contact.php`)

- Honeypot (`website`), per-IP rate limit (5 per 10 minutes), validation (name, email or phone, consent).
- Sends from/to `info@oklahomainsuranceappraiser.com` over authenticated SMTP (`smtp.hostinger.com:465`)
  when `public_html/api/_private/config.php` exists, else falls back to `mail()`. Every submission is appended
  to `api/_private/leads.log.php` (JSON lines, with `"via":"smtp"` / `"none+mail"` etc.).
- Both private files 404 when requested directly: the config starts with
  `<?php defined('OIA_CONFIG_OK') || (http_response_code(404) && exit);` and the log starts with
  `<?php http_response_code(404); exit; ?>`. Hostinger's file API can't write outside `public_html`, so they live there.
- **Never commit credentials.** `_private/` is in `.gitignore`. Keep any local copy of the config outside the
  repo and delete it after upload. Config shape:
  `return ['smtp_host'=>'smtp.hostinger.com','smtp_port'=>465,'smtp_user'=>'info@oklahomainsuranceappraiser.com','smtp_pass'=>'…'];`
- Once the mailbox exists: upload the config, confirm `/api/_private/config.php` returns 404 with 0 bytes,
  send one submission labelled as a test, and confirm the log shows `"via":"smtp"`.

## SEO rules (enforced by `validate.py`)

- Titles ≤ 60 characters and ≤ ~580px (Arial 20px estimate); titles and descriptions unique.
- Hand-written meta descriptions on every page, **110–143 characters** (under 144), ending in a full sentence;
  `og:description` and `twitter:description` match.
- Exactly one H1, first heading is the H1, no skipped levels (footer, sidebar boxes and tools included).
- Valid JSON-LD; every `@id` reference resolves; every graph has ProfessionalService (logo, contactPoint,
  addressRegion/country, areaServed, OfferCatalog), WebSite, BreadcrumbList and exactly one page node
  (WebPage/AboutPage/ContactPage/CollectionPage) with `breadcrumb`, `primaryImageOfPage` and `mainEntity`.
  Service (services, cities), FAQPage, ItemList (index pages), WebApplication (tools), BlogPosting (guides),
  HowTo (process) and DefinedTermSet (glossary) where they apply.
- No broken internal links or anchors, every image has `alt`, canonical/OG/Twitter/`geo.region` present.
- Homepage main content contains "Oklahoma Insurance Appraiser" at least 14 times.
- No sister-state names anywhere in the build (list in `validate.py`).
- Every `dir/index.php` starts with the guard line and contains no other PHP.

## Design

- Palette: brand green `#1d5c42`, deep `#0f3626` / `#0a2619`, light tint `#e6f0ea`, red-clay accent `#c4552f`
  (complement of the green; nods to Oklahoma red dirt), warm sand neutral `#f8f4ed`, ink `#15231c`.
- Fonts: **Lexend** (display) + **Libre Franklin** (body) via Google Fonts; monospace numerals in tool outputs.
- Effects: floating pill header that compacts on scroll, scroll progress bar, Ken Burns hero zoom, staggered
  reveal and clip-path wipe, animated counters, hover zoom on cards, horizontal process stepper that fills on
  scroll (vertical on mobile), expanding region panels, parallax CTA and back-to-top button with a progress ring.
  All respect `prefers-reduced-motion`; content is visible without JavaScript.
- Mobile: off-canvas drawer outside the sticky header (accordion sections, scroll lock, closes via ×, overlay,
  link tap or Escape, `inert`/`aria-hidden` handling, shadow only while open) and a fixed bottom call bar.
- Icons: `favicon.svg`, multi-size `favicon.ico` (16/32/48, bolder mark), 96px PNG, full-bleed 180px
  `apple-touch-icon.png`, maskable 192/512 PNGs in `site.webmanifest`, all with `?v=` cache-busters.
  OG image: `assets/img/og-image.jpg` (1200×630, from a site photo).
