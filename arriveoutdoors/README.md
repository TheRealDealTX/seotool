# arriveoutdoors.com — static rebuild

Replaces the WordPress site with a fast static HTML/PHP site: free camping and
hiking tools, month-by-month weather guides for 20 parks, 24 rewritten or new
guides, and a curated gear page. No database, no plugins.

| Path | What it is |
| --- | --- |
| `public/` | **The generated site — this is what gets uploaded** to `public_html` |
| `build.py` | Generator (Python 3 standard library only) |
| `validate.py` | Post-build checks: links, redirects, titles, schema |
| `siteconfig.py` | Site settings, author byline, URL inventory, **redirect + 410 map** |
| `content/articles/*.html` | Guides (metadata block + HTML body) — see `CONTENT_GUIDE.md` |
| `content/destinations/*.json` | Editorial copy for each destination guide |
| `content/tools.py`, `assets/js/tools/*.js` | Tool page copy/forms and their logic |
| `content/gear.py` | Gear page items (Amazon tag `arriveoutdoors-20`) |
| `data/climate.json` | 2015–2024 monthly climate normals (Open-Meteo ERA5), from `scripts/fetch_climate.py` |
| `REDIRECTS.md` | What happened to every old URL (generated by `scripts/redirect_report.py`) |
| `source-archive/` | Text of the 30 WordPress posts before the rewrite |
| `backup-wordpress/` | The two WordPress files the deploy overwrites, for rollback |

## Build and deploy

```sh
python3 build.py && python3 validate.py
python3 scripts/redirect_report.py   # after changing redirects
./deploy.sh                          # needs upload credentials, see the script header
```

Then purge the LiteSpeed cache in hPanel.

## Adding content

- New guide: add `content/articles/<slug>.html` following `CONTENT_GUIDE.md`, add the slug to `ARTICLES` in `siteconfig.py`, optionally a hero image at `assets/img/posts/<slug>.webp`.
- New destination: add a row to `DESTINATIONS`, run `scripts/fetch_climate.py`, add `content/destinations/<slug>.json`.
- Author: replace `AUTHOR` in `siteconfig.py` with a real person as soon as possible.
