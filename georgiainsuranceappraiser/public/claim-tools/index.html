Six calculators and planners built from real appraisal work. Use them to understand your claim, check the carrier’s math and decide on next steps — no sign-up, nothing stored.

Using the tools together

  1. Start with the deadline planner so nothing lapses.
  2. Check the roof math with the squares & pitch calculator.
  3. See what you’re actually owed with the deductible and depreciation calculators.
  4. Test the dispute with the appraisal value estimator.
  5. Finish with the readiness score.
