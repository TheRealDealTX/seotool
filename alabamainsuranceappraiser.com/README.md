# alabamainsuranceappraiser.com — custom HTML/PHP rebuild

Replaces the WordPress/Elementor site with a hand-built HTML + PHP site: static
pages generated by Python, a PHP front controller that keeps every old URL
working, and a PHP contact form that sends through the site mailbox over SMTP.
No WordPress, no database, no plugins.

Live since 2026-11-05 on the Hostinger Agency Growth plan, website UID
**`rMIbFS7kW`** (plain `php-fpm`, PHP 8.5).

## Layout

| Path | What it is |
| --- | --- |
| `build.py` | Generator — renders every page into `public_html/` and copies `static/` |
| `siteconfig.py` | Business facts, city list, services, tools, navigation |
| `components.py` | Shared layout (header, footer, heroes, cards, FAQ, forms) and JSON-LD builders |
| `content/` | Page copy: `home.py`, `services.py`, `areas.py`, `tools.py`, `posts.py`, `pages.py` |
| `static/` | Copied as-is: `index.php`, `api/contact.php`, CSS/JS, images, icons, original `wp-content/uploads/` |
| `public_html/` | **The build output** — this folder is what gets deployed |
| `validate.py` | Post-build checks |
| `deploy.sh` | Uploads `public_html/` to the Hostinger website |
| `backup/wordpress-2026-11-05/` | Rendered HTML of every old page, old sitemaps, WP REST exports |

```sh
python3 build.py && python3 validate.py    # build + check
cd public_html && php -S 127.0.0.1:8000 index.php   # rough local preview (static files + router)
```

Only the Python 3 standard library is needed to build.

## SEO & schema

Every page: unique title and meta description, one H1, canonical, Open Graph +
Twitter tags, `geo.region`, and a JSON-LD `@graph` containing:

* `ProfessionalService` + `LocalBusiness` (`#organization`) — name, logo, phone,
  email, `areaServed` (Alabama + 11 cities), `knowsAbout`, `hasOfferCatalog` of all
  11 services. No street address is published (the business is statewide and has
  none on the old site), so `address` carries region/country only.
* `WebSite`, a typed `WebPage` (`AboutPage`, `ContactPage`, `CollectionPage`…),
  `BreadcrumbList`.
* Per page type: `Service` (+ `City` areaServed on area pages), `FAQPage`,
  `BlogPosting`/`Blog`, `WebApplication` + `HowTo` on tools, `HowTo` on the process
  page, `DefinedTermSet` on the glossary, `ItemList` on hubs.

`sitemap.xml` and `robots.txt` are generated by the build.

## Contact form

`static/api/contact.php` validates the form, filters spam (honeypot, minimum
fill time, link count, same-origin check, 5/hour per-IP limit), writes a backup
copy of every lead, and emails it to `info@alabamainsuranceappraiser.com` through
`smtp.hostinger.com:465` (authenticated as that mailbox), falling back to PHP
`mail()` if SMTP fails. Without JS the form posts normally and redirects to
`/thank-you/`.

**Credentials are not in git.** They live in `.h5g/aia-config.php` beside
`public_html` on the server (outside the web root; the Agency File Browser
can't write to the account root, so `.h5g/` is used):

```php
<?php return ['smtp_host' => 'smtp.hostinger.com', 'smtp_port' => 465,
              'smtp_user' => 'info@alabamainsuranceappraiser.com',
              'smtp_pass' => '…', 'to' => 'info@alabamainsuranceappraiser.com'];
```

If the mailbox password changes, re-upload that file (TUS upload to
`.h5g/aia-config.php`, see `deploy.sh` for the request shape). Lead backups are
written to `.h5g/aia-leads/leads-YYYY-MM.jsonl`.

### Hosting notes

* The platform serves existing files directly and routes `/` and unknown paths
  to `index.php`; it ignores `.htaccess`. There is deliberately **no root
  `index.html`** — the homepage is `home.html`, served by `index.php`
  (and `Disallow`ed in robots.txt, canonical to `/`).
* `http://` and `www.` requests for the homepage and unknown paths are 301'd to
  `https://alabamainsuranceappraiser.com` by `index.php`. Existing static pages
  requested over `http://`/`www.` are served directly by the platform (no PHP
  runs), so they rely on their canonical tags.

## The old WordPress site (rollback)

The WordPress website (UID `dXa6n8AXT`) was **not deleted**. Its primary domain
was changed to `wp-old.alabamainsuranceappraiser.com` (also reachable at
`dimgrey-cheetah-219027.hostingersite.com`) so the main domain could move to the
new site. A `robots.txt` with `Disallow: /` was added to its web root so the old
copy isn't crawled as duplicate content.

To roll back: change `rMIbFS7kW`'s domain back to its temporary domain, then
change `dXa6n8AXT`'s domain from `wp-old.…` to `alabamainsuranceappraiser.com`
(`agency-hosting_domains_change-website`), and delete that `robots.txt`.
Once you're happy with the new site, the WordPress website can be deleted.
