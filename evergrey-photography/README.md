# evergrey-photography.com — rebuild

A static rebuild of the expired domain **evergrey-photography.com**: a Victoria, BC
wedding, elopement and engagement photographer. HTML/CSS/JS generated by Python,
served by a small PHP front controller.

**Live:** https://www.evergrey-photography.com (Hostinger Agency Growth, website UID `3lik6FHqr`;
temporary hostname lemonchiffon-bison-485522.hostingersite.com still answers but sends
`X-Robots-Tag: noindex`). The bare domain and http 301 to `https://www.`.

## SEO setup

- Google tag `G-BTLDQSK5EM` first in `<head>` on every page (incl. 404); the inquiry form also
  sends a `generate_lead` event on success.
- Google Search Console file verification: `public/googlecccfbf2f7e9e5ae4.html` (written by `build.py`).
- `sitemap.xml` (with image entries), `robots.txt`, `feed.xml` (RSS for the Journal).
- Favicons: `favicon.ico` (16/32/48), `favicon.svg`, `favicon-96x96.png`, `apple-touch-icon.png`,
  `site.webmanifest` with 192/512 icons.
- Per page: unique title + description, one keyword H1, canonical, Open Graph/Twitter with
  1200x630 JPEG share images (`assets/img/og/`), JSON-LD (LocalBusiness, WebSite, BreadcrumbList,
  Service, FAQPage, BlogPosting, WebApplication, ImageGallery). `validate.py` enforces all of it.

## Layout

| Path | What it is |
| --- | --- |
| `build.py` | Generator: layout, every page, schema, sitemap, robots, favicons |
| `siteconfig.py` | Business details, nav, sun-tool locations, elopement spots, pricing |
| `content/posts_*.py` | The 14 journal posts (3 real-wedding stories + 11 guides) |
| `validate.py` | Post-build checks (one H1, titles/descriptions, links, images, JSON-LD, legacy URLs) |
| `deploy.sh` | Uploads `public/` through the Hostinger File Browser TUS API |
| `public/` | **The deployable site** (upload its contents to `public_html/`) |
| `public/index.php` | Router: serves `_pages/<route>.html` at slash-less URLs, 301s legacy paths, real 404s |
| `public/contact.php` | Inquiry form handler — emails `info@evergrey-photography.com` via PHP `mail()` |

```sh
python3 build.py && python3 validate.py
export EG_FB_URL=… EG_FB_AUTH=… EG_FB_REST=…   # from agency-hosting_files_generate-upload-url
./deploy.sh                                       # then clear the website cache
```

## Legacy URLs preserved

The old site was on Wix, so URLs had no trailing slash. These are served at exactly the
same paths (no redirect):

- `/` — all ranking keywords (victoria wedding photography, best wedding photographers victoria bc,
  photography victoria bc, bc wedding photography, affordable photographer victoria bc…) and ~530 backlinks
- `/about` — backlinks
- `/post/kasha-justin` — ranked for "aylard farm sooke"
- `/post/sarina-riley`, `/post/florence-kyle` — backlinks
- `/blog`, `/contact`, plus 301s for common Wix-era guesses (`/gallery`, `/investment`, `/home`, `/blog/categories/*`…)

Home, About, Weddings, Elopements, Engagements, Portfolio (filter + lightbox), Pricing
