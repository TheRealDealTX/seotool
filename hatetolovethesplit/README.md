# hatetolovethesplit.com — rebuild

A static rebuild of the expired split-level renovation blog **Hate to Love the Split**
(Minneapolis, 2014–2016). Plain HTML/CSS/JS generated by `build.py` (Python stdlib only),
served by a tiny `index.php` front controller on a plain php-fpm Hostinger site.

```sh
python3 build.py      # writes ./public
python3 validate.py   # legacy URLs, broken links/assets, one H1, unique titles
./deploy.sh           # see header comment for credentials
```

## What was rebuilt (and why)

Source data: the Semrush organic positions export and backlinks export.

- **Backlinks:** all 690 point at the homepage (`/`), so the homepage is the strongest page.
  Anchors (“Emelia”, Deuce Cities Henhouse, Making it Lovely) identify it as a Twin Cities
  DIY/renovation blog by Emelia, which set the voice and topic.
- **Ranked URLs:** all 49 URLs in `legacy-urls.txt` exist at their original paths:
  12 posts (e.g. `/2014/02/07/akurum-cabinets/`, `/2014/07/07/lilac-trimming/`),
  31 tag pages, 5 category pages (incl. `/category/random-thoughts/page/2/`), the
  `/2014/11/` month archive and the homepage. Each page is written around the keywords
  it ranked for (ikea akurum, trimming lilacs, built in kegerator, ribba frame instructions,
  cement pavers, white tongue and groove ceiling, weslock door knob removal, …).
- **11 new posts** (marked `new` in `content/posts.py`) give the ranked tag pages real
  content (bathroom reveal, Ironman bike ride, Pax closet, Nordeast night out, …).
- The Wayback Machine was unreachable from the build environment, so post bodies are new
  writing, not copies of the original posts.

Extras: month/year archives, `/archives/`, `/projects/`, `/about/`, `/contact/` (form posts to
`contact.php`, which mails info@hatetolovethesplit.com; a mailbox for the domain must exist for
delivery), `/privacy-policy/`, `sitemap.xml`, `robots.txt`, RSS at `/feed/`.

## Design

Fraunces / Inter / Caveat, ink-plum + rose + lilac palette. Effects: Ken Burns hero with
animated “~~hate~~ → love” headline, floating gradient blobs, tag marquee, scroll reveals,
counters, a draggable hate/love before-after slider, card tilt, reading-progress bar,
parallax heroes. Off-canvas mobile nav with focus trap, Esc/scrim close, honours
`prefers-reduced-motion`.

Images: royalty-free (StockSnap CC0 and Pexels), converted to WebP in `assets/img/`.
