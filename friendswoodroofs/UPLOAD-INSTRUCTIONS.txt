FRIENDSWOOD ROOFERS - MANUAL UPLOAD (Hostinger hPanel File Manager)
====================================================================

The zip contains two folders:
  public_html/   the website's public files
  app/           the private application code (PHP, templates, content, PHPMailer)

1. In hPanel, open the friendswoodroofs.com website > Files > File Manager.
   Go to the domain folder that CONTAINS public_html
   (often /domains/friendswoodroofs.com/ ; on some plans it is the home folder).

2. Upload friendswoodroofs-site.zip there and Extract it.
   Result:   .../public_html/index.php
             .../app/bootstrap.php        (app sits NEXT TO public_html)
   Delete any default index.html / default.php Hostinger put in public_html.

   If File Manager will not let you write outside public_html:
   move the "app" folder INTO public_html (public_html/app). That works too;
   it is blocked from web access by app/.htaccess.

3. hPanel > Advanced > PHP Configuration: choose PHP 8.1 or newer (8.2/8.3 recommended).
   hPanel > Security > SSL: make sure SSL is active for friendswoodroofs.com.

4. EMAIL (required for the estimate form to deliver):
   a. hPanel > Emails: create a mailbox, e.g. estimates@friendswoodroofs.com
   b. In File Manager, open app/config/, copy mail.example.php to mail.php,
      edit mail.php and set username / from_email to that mailbox and
      password to its password. Submissions go to teamwriteforus.today@gmail.com.
   c. hPanel > Emails > DNS / Authentication: enable SPF, DKIM and add DMARC.
   Until mail.php exists, the form tells visitors their request could not be sent
   and asks them to call (no false success).

5. Check: https://friendswoodroofs.com/ , /sitemap.xml , /robots.txt ,
   a made-up URL (should show the custom 404), then send a test estimate request.

6. Optional: set the article launch date in app/config/site.php ("launch_date").
