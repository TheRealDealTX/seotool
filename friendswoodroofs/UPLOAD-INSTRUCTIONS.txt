FRIENDSWOOD ROOFERS - MANUAL UPLOAD (Hostinger hPanel File Manager)
====================================================================

Use friendswoodroofs-public_html.zip. Everything goes INSIDE public_html.

1. hPanel > friendswoodroofs.com website > Files > File Manager > open public_html.
   Delete Hostinger's default files there (default.php / index.html), if any.

2. Upload friendswoodroofs-public_html.zip into public_html and Extract it there
   (extract to the current folder, not into a new subfolder). You should see:
       public_html/index.php
       public_html/.htaccess        (hidden file - must be present)
       public_html/assets/
       public_html/app/             (private code; blocked from the web)
   Then delete the zip file.
   Tip: if .htaccess isn't visible, turn on "Show hidden files" in File Manager.

3. hPanel > Advanced > PHP Configuration: PHP 8.1 or newer (8.2/8.3 recommended).
   hPanel > Security > SSL: make sure SSL is active.

4. EMAIL (needed for the estimate form to deliver to teamwriteforus.today@gmail.com):
   a. hPanel > Emails: create a mailbox, e.g. estimates@friendswoodroofs.com
   b. File Manager: public_html/app/config/ -> copy mail.example.php to mail.php,
      edit mail.php: set username and from_email to that mailbox, password to its password.
   c. hPanel > Emails > DNS / Authentication: enable SPF and DKIM, add DMARC.
   Until mail.php exists, the form tells visitors the request could not be sent
   and asks them to call (no false success).

5. Check in a browser:
   https://friendswoodroofs.com/            home page
   https://friendswoodroofs.com/sitemap.xml
   https://friendswoodroofs.com/app/config/site.php   -> must show the "page not found" page
   then send a test estimate request.

6. Optional: article launch date = "launch_date" in public_html/app/config/site.php.

Security note: public_html/app is protected by two .htaccess rules (the main
.htaccess and app/.htaccess). This was tested on Apache; do not delete either file.
