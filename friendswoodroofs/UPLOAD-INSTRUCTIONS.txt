FRIENDSWOOD ROOFERS - MANUAL UPLOAD (Hostinger hPanel File Manager)
====================================================================

Use friendswoodroofs-public_html.zip. Everything goes INSIDE public_html.
(This Hostinger platform serves files directly and ignores .htaccess, so the
private "app" folder is protected in PHP instead: every file in it exits
immediately if requested from a browser.)

FIRST UPLOAD
1. hPanel > friendswoodroofs.com > Files > File Manager > open public_html.
   Delete Hostinger's default files (default.php / index.html), if any.
2. Upload friendswoodroofs-public_html.zip into public_html and Extract it
   there (current folder, not a new subfolder). Then delete the zip.
   You should see public_html/index.php, public_html/assets/, public_html/app/.

UPDATING AN EXISTING UPLOAD
1. Upload the new zip into public_html and Extract with "overwrite" / replace.
   Your app/config/mail.php is NOT in the zip, so it is kept.
2. Delete these leftovers from older uploads if they exist (they are readable
   from the web and no longer needed):
     public_html/app/composer.json
     public_html/app/composer.lock
     public_html/app/docs/                      (whole folder)
     public_html/app/storage/secret.key
     public_html/app/vendor/composer/installed.json
     public_html/app/vendor/phpmailer/phpmailer/README.md
     public_html/app/vendor/phpmailer/phpmailer/SECURITY.md
     public_html/app/vendor/phpmailer/phpmailer/VERSION
     public_html/app/vendor/phpmailer/phpmailer/composer.json
     public_html/app/vendor/phpmailer/phpmailer/LICENSE
     any *.log or *.json files in public_html/app/storage/logs and .../ratelimit
   Also delete public_html/README.md, public_html/UPLOAD-INSTRUCTIONS.txt or a
   nested public_html/public_html/ folder if an earlier zip created them.

ALWAYS
3. PURGE THE CACHE: hPanel > friendswoodroofs.com > Performance (or Cache /
   CDN) > Purge all / Clear cache. The CDN may still be serving the old
   WordPress homepage at https://friendswoodroofs.com/ until you do this.
4. PHP 8.1 or newer (Advanced > PHP Configuration). SSL active (Security > SSL).
5. EMAIL (estimate form -> teamwriteforus.today@gmail.com):
   a. Emails: create a mailbox, e.g. estimates@friendswoodroofs.com
   b. File Manager: public_html/app/config/ -> copy mail.example.php to mail.php,
      set username and from_email to the mailbox and password to its password.
   c. Emails > DNS / Authentication: enable SPF and DKIM, add DMARC.
6. Check in a browser (use a private window):
   https://friendswoodroofs.com/                      new homepage
   https://www.friendswoodroofs.com/                  redirects to the line above
   https://friendswoodroofs.com/app/config/mail.php   must be a BLANK page
   then send a test estimate request and confirm it arrives in Gmail.
